# RisuTalk

리수(RisuAI) 캐릭터와 메신저처럼 톡하는 웹앱.
캐릭터 카드·로어북·기억을 그대로 불러와, 카카오톡 같은 화면에서 대화합니다.

- 1:1 톡 · 단톡 
- 사진/셀카 생성 (GPT · NovelAI) · 사진 보내기
- 번역 · 로어북 · 기억 자동 요약
- 날씨 · 테마 · 기기 간 동기화 · PWA 설치

---

## 배포

각자 자기 Vercel에 배포해서, **자기 API 키로** 씁니다.
제작자의 키를 빌려 쓰는 구조가 아닙니다. 키도 요금도 각자의 것입니다.

### 빠르게 (버튼 한 번)

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/USERNAME/REPO)

버튼을 누르면 저장소 복사와 배포가 한 번에 됩니다.
배포가 끝나면 아래 **키 넣기**로 넘어가세요.

### 직접 (나중에 갱신받으려면 이쪽)

1. 오른쪽 위 **Fork** 로 이 저장소를 자기 GitHub에 복사
2. Vercel → Add New → Project → 복사한 저장소 선택 → Deploy

### 키 넣기

3. Vercel → Settings → Environment Variables 에 쓸 기능의 키를 넣습니다
   (무엇을 넣는지는 `.env.example` 참고)
4. **Deployments → 맨 위 배포 → ⋯ → Redeploy**
   환경변수는 다시 배포해야 반영됩니다. 이 단계를 빠뜨리는 경우가 가장 많습니다.
5. 앱 → 설정 → 모델 에서 제공자와 모델명 지정

자세한 설정과 오류 대처는 **설명서**를 참고하세요.

> `package.json` 을 만들지 마세요. Edge 런타임으로 도는 구조입니다.

## 갱신받기

고쳐진 내용은 각자 원할 때 가져갑니다. 자동으로 바뀌지 않으므로
쓰던 배포가 갑자기 깨지는 일은 없습니다.

1. 자기 저장소 첫 화면의 **Sync fork** → **Update branch**
2. Vercel이 알아서 다시 배포합니다 (환경변수는 그대로 유지됩니다)

버튼으로 배포한 경우에도 같은 방법으로 갱신할 수 있습니다.

## 키와 보안

- **프록시 모드** — 키를 Vercel 환경변수에 넣으면 브라우저로 내려가지 않습니다.
- **직접 호출 모드** (Gemini·Anthropic·OpenAI 등) — 앱에 입력한 키는 그 기기의
  브라우저에 저장됩니다. 공용 기기에서는 직접 입력하지 마세요.
- 백업 파일과 동기화 데이터에는 키와 동기화 코드가 들어가지 않습니다.
- 동기화 코드는 저장된 대화를 여는 비밀번호입니다. **20자 이상 무작위**로 정하고,
  다른 곳에 쓰는 비밀번호와 같은 값을 쓰지 마세요.

> ### ⚠️ PROXY_KEY 를 설정하세요
>
> 배포한 주소는 링크를 공유하지 않아도 인터넷에서 접근 가능합니다.
> `PROXY_KEY` 를 설정하지 않으면, 주소를 알아낸 사람이 API를 직접 호출해
> **배포자의 API 요금을 쓸 수 있습니다.**
>
> Vercel 환경변수와 앱의 "키" 칸에 같은 값을 넣으면 됩니다.
> API 회사에서 발급받는 키가 아니라, 직접 만드는 24자 이상의 무작위 문자열입니다.

GemTi 연동에는 GemTi 플러그인과 같은 OAuth 클라이언트 값이 코드에 들어 있습니다.
공개된 값이며, 사용자 개인 키가 아닙니다.

### Vertex AI

구글 클라우드 서비스 계정 JSON을 받아 `VERTEX_PROJECT_ID`, `VERTEX_CLIENT_EMAIL`,
`VERTEX_PRIVATE_KEY` 에 옮겨 적고, 제공자를 **프록시 · 서버 키** 로 둔 뒤
모델 칸에 `vertex/gemini-3.6-flash` 처럼 `vertex/` 를 붙여 입력합니다.

`VERTEX_LOCATION` 은 `global` 을 권장합니다. 최신 모델은 특정 지역에 열려 있지 않아
`us-central1` 등으로 두면 404가 납니다.
